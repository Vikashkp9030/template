# Thermal templates

Paper sizes: **58mm** and **80mm**. Preview width and ESC/POS column width follow `ThermalPaperSize`.

| Type | Class | Look |
| --- | --- | --- |
| `classic` | `ClassicThermalTemplate` | Centered store name, dashed rules, cash/change |
| `modern` | `ModernThermalTemplate` | Logo, customer/order, QR, boxed total |

Register new templates in `ThermalTemplateRegistry`.
